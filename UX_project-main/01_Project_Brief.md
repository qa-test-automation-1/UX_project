# TaskFlow — Project Brief

## Opis aplikacji
TaskFlow to prosta aplikacja do zarządzania codziennymi zadaniami. Użytkownik może szybko dodawać, przeglądać i oznaczać zadania jako wykonane.

## Problem
Użytkownicy potrzebują prostego narzędzia do zapisywania zadań bez konieczności korzystania z rozbudowanych systemów zarządzania projektami.

## Cel UX
Stworzenie minimalistycznego interfejsu, który pozwala szybko:
- zobaczyć swoje zadania,
- dodać nowe zadanie,
- oznaczyć zadanie jako wykonane.

## Zakres
Projekt obejmuje Dashboard, ekran dodawania zadania, potwierdzenie dodania oraz podstawowy prototyp interaktywny.

## Grupa docelowa
Osoby potrzebujące prostego narzędzia do organizowania codziennych obowiązków.

## Rezultat
Prototyp aplikacji TaskFlow przygotowany w Figma.
