# TaskFlow — User Research

## Cel
Poznanie sposobu organizowania codziennych zadań oraz najważniejszych potrzeb użytkowników aplikacji typu To-Do.

## Metoda
Ćwiczeniowe badanie jakościowe:
- 5 uczestników,
- krótkie wywiady,
- analiza sposobu organizowania zadań.

> Badanie jest fikcyjne i służy wyłącznie jako element projektu UX.

## Pytania
1. Jak obecnie zapisujesz swoje zadania?
2. Jak często dodajesz nowe zadania?
3. Co najbardziej przeszkadza Ci w aplikacjach To-Do?
4. Co powinno być widoczne od razu po uruchomieniu aplikacji?
5. Jak oznaczasz zadanie jako wykonane?

## Wnioski
- Użytkownicy oczekują szybkiego dodawania zadań.
- Formularz powinien być możliwie prosty.
- Lista zadań powinna być głównym elementem Dashboardu.
- Status wykonania powinien być jednoznaczny.
- Interfejs nie powinien zawierać zbędnych funkcji.

## Wnioski projektowe
TaskFlow powinien koncentrować się na dodawaniu, przeglądaniu i oznaczaniu zadań jako wykonane.
